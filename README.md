"# Simple_Number_Guessing_Game" 
It is a simple number guessing game.
First, the computer generates a number.
Next, the computer prompts the user to guess a number.
If the the user guess is equal to the computer number, it will print correct.
Otherwise, it will run the program until the user guess the correct number.
This program uses if and else for checking the condation.
And also, it uses a while loop for repeating the code until the condition become true.
Next, the program uses a try and except block for handling the invalid input to manage the erros.
